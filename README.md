# hh-jobs-finder

Авто-отклики на hh.ru: система сама ищет вакансии по твоим фильтрам, отсеивает
неподходящие, пишет персональное сопроводительное письмо под каждую и отправляет
отклик. Запускается по расписанию или из приложения в меню-баре macOS.

Работает поверх [Claude Code](https://claude.com/claude-code): пайплайн — это набор
скиллов, сабагентов и slash-команд, а браузером управляет Playwright MCP.

```
поиск hh.ru  →  анализ под резюме  →  письмо  →  отклик
  collector       analyzer            letter      applier
```

- **collector** — обходит поисковые запросы, собирает новые вакансии в реестр.
- **analyzer** — сверяет вакансию с резюме и правилами матчинга: `match` или `skip` с причиной.
- **letter** — пишет письмо по методу X-Y-Z и прогоняет через три гейта (стиль, длина, факты).
- **applier** — жмёт «Откликнуться», вставляет письмо (модалка, чат или тест работодателя).

Всё пишется в `data/vacancies-registry.yaml`, по каждому прогону — отчёт в
`data/run-reports/`.

## Требования

| Что | Зачем | Проверить |
|---|---|---|
| macOS | приложение и планировщик launchd | — |
| [Claude Code](https://claude.com/claude-code) | выполняет пайплайн | `claude --version` |
| Node.js 18+ | Playwright MCP, проверка авторизации | `node -v` |
| Google Chrome | Playwright ходит именно каналом chrome | — |
| Rust + cargo | сборка приложения (только если нужен GUI) | `cargo --version` |
| Python 3 | форматирование живого лога | `python3 -V` |

Аккаунт hh.ru с **опубликованным резюме** — откликаться нужно чем-то.

## Установка

```bash
git clone git@github.com:vahagncrypto99-netizen/hh-jobs-finder.git
cd hh-jobs-finder
./install.sh
```

`install.sh` делает всё разом и идемпотентно:

1. проверяет node / npm / claude / cargo / python3;
2. регистрирует **Playwright MCP** (`claude mcp add playwright --scope user`);
3. докачивает браузеры Playwright (chromium + канал chrome);
4. ставит зависимости приложения и собирает `.app`;
5. проверяет вход на hh.ru.

Флаги:

```bash
./install.sh --check          # только диагностика, ничего не меняет
./install.sh --with-schedule  # плюс установка launchd-агента
./install.sh --no-build       # без сборки .app
```

## Настройка

### 1. Резюме и конфиг

Два приватных файла, которых нет в репозитории (см. `.gitignore`):

- `config.yaml` — фильтры поиска, контакты, правила матчинга;
- `resume.md` — твой опыт; **единственный источник фактов для писем**.

Самый быстрый путь — приложение: таб **Settings → Set resume…**, выбрать своё резюме
(pdf, docx, md, txt). Команда `/hh:init` разберёт его и заполнит оба файла.

То же самое из терминала:

```bash
claude
> /hh:init ~/Downloads/resume.pdf
```

В интерактивном режиме команда спросит то, чего в резюме нет (зарплата, поисковые
запросы, формат работы). Из приложения она запускается в авторежиме: берёт разумные
умолчания и в конце перечисляет, что стоит проверить руками.

Вручную — скопировать примеры и отредактировать:

```bash
cp config.yaml.example config.yaml
cp resume.md.example resume.md
```

**`resume.md` важнее, чем кажется.** Раздел «Достижения с метриками» — то, из чего
собираются письма. Цифры оттуда попадают в текст дословно, выдумывать их скиллу прямо
запрещено. Раздел «Чего НЕТ» страхует от приписывания несуществующего опыта.

### 2. Фильтры поиска

Правятся либо в `config.yaml`, либо в приложении (таб Settings) — это один и тот же файл,
изменения ходят в обе стороны.

```yaml
search:
  filters:
    text: ["Laravel", "Backend разработчик"]   # запросы обходятся по очереди
    salary: 2000
    currency_code: "USD"       # USD | EUR | RUR | KZT | UAH | GEL | AZN | KGS | UZS | BYR
    experience: "between3And6" # noExperience | between1And3 | between3And6 | moreThan6
    work_format: "REMOTE"      # REMOTE | HYBRID | ON_SITE | FIELD_WORK
    search_period: 3           # за сколько суток: 1 | 3 | 7 | 30 | 0 (за всё время)
```

### 3. Правила матчинга

Определяют, какие вакансии отсеиваются без обращения к модели:

```yaml
matching:
  title_blacklist: [Team Lead, Тимлид, CTO]        # хард-скип по заголовку
  framework_blacklist: [Yii2, Symfony, Bitrix]     # чужой основной фреймворк → скип
  primary_languages: [PHP]                         # основной язык вакансии
  core_stack: [PHP, Laravel, PostgreSQL, Redis]    # совпадение → match
  learnable_tech: [Livewire, Alpine.js]            # отсутствие в резюме не считается пробелом
  doubt_policy: match                              # что делать при сомнении
```

### 4. Вход в hh.ru

Один раз, чтобы cookies осели в профиле Playwright:

```bash
claude
> /hh:login
```

Откроется браузер — залогинься руками и напиши «готово». Дальше проверять вход можно
кнопкой **Check** в приложении или `./scripts/check-auth.sh` (без ИИ, ~5 секунд).

## Запуск

```bash
./hhru-jobs --dry-run --verbose   # прогон без реальных откликов — начни с него
./hhru-jobs                       # боевой прогон
./hhru-jobs --w=3 -c 10           # 3 воркера, максимум 10 новых вакансий
```

Или из приложения: таб **Run → Run now** (чекбокс `Dry run` рядом).

`make run` / `make dry` — то же самое через Makefile.

### По расписанию

```bash
./scheduler/install.sh
```

Ставит launchd-агента `com.hh-jobs` (по умолчанию 09:00 и 22:00). Время правится в
приложении: **Run → Schedule**, чипы времени сохраняются сразу и агент перезагружается сам.
Логи: `data/run-reports/launchd.log`.

## Приложение (меню-бар)

```bash
cd app && npm run dev      # окно разработки
cd app && npm run build    # сборка .app
```

Готовый бандл: `app/src-tauri/target/release/bundle/macos/hh-jobs.app`. Живёт только в
меню-баре, иконки в доке нет; клик по иконке открывает панель, Escape её прячет.

**Run** — статусы пайплайна, планировщика и сессии hh.ru; запуск и остановка; панель
прогресса (стадия + счётчики found / analyzed / skipped / applied, числа берутся из
реестра, а не из лога); расписание.

**Settings** — импорт резюме, режим письма, поисковые запросы, фильтры, лимиты прогона.
Кнопок «Сохранить» нет: правки уходят в `config.yaml` сами, комментарии и форматирование
файла при этом сохраняются.

## Режимы написания письма

```yaml
letter:
  mode: ai                        # ai | template
  template: "templates/letter.md"
```

- **`ai`** (по умолчанию) — письмо пишется под конкретную вакансию: выбирается одно
  релевантное достижение, письмо проходит гейты на естественность (`ru-ai-check`, порог
  7.0/10), длину и фактическую точность. Дороже и медленнее, но письма не похожи друг на друга.
- **`template`** — сборка по `templates/letter.md`: подстановка переменных и выбор блока
  опыта по теме вакансии. Мгновенно и бесплатно, но внутри одной темы письма получаются
  почти одинаковыми. Уместно для dry-run, отвала ИИ и вакансий, где нужен сам факт отклика.

Свой шаблон: `cp templates/letter.md.example templates/letter.md` и заменить
`{{плейсхолдеры}}` на факты из резюме.

## Структура

```
.claude/
  agents/       hh-collector, hh-analyzer, hh-letter, hh-applier
  commands/hh/  init, login, run
  skills/       hh-parsing, hh-matching, hh-letter, hh-applying

scripts/        check-auth.sh, format-stream.py

hhru-jobs       точка входа в пайплайн
install.sh      установка зависимостей
```

## Диагностика

| Симптом | Что делать |
|---|---|
| `AUTH_FAIL`, редирект на вход | `/hh:login` — сессия истекла |
| «профиль занят» при проверке | открыт браузер пайплайна; дождись конца прогона |
| Планировщик `not loaded` | `./scheduler/install.sh` |
| Пусто в выдаче | ослабь фильтры: `search_period`, `salary`, `experience` |
| Все вакансии в `skipped` | слишком строгие `title_blacklist` / `framework_blacklist`; причина скипа лежит в реестре в `verdict_reason` |
| Письма не сходятся за 5 итераций | мало конкретики в «Достижениях с метриками» — добавь цифр |
| `claude` не найден из приложения | приложение запущено из Finder с урезанным PATH; проверь `./install.sh --check` |

Полная диагностика окружения: `./install.sh --check`.

## Приватность

В репозиторий не попадают: `config.yaml` (контакты), `resume.md`, `templates/letter.md`,
сгенерированный plist с абсолютными путями и весь каталог `data/` — реестр вакансий,
письма, отчёты и логи. Проверить перед коммитом: `git status --short`.

Система ничего никуда не отправляет, кроме самих откликов на hh.ru от твоего имени.
